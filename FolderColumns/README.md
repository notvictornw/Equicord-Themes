# FolderColumns

Layout multi-coluna para a sidebar do [BetterFolders](https://github.com/Vendicated/BetterFolders). Precisa do plugin com a sidebar ativada.

Coloca os servidores em 1–4 colunas dentro da sidebar que abre ao clicar numa pasta, via `flex-wrap`. Não mexe na barra principal.

## Instalação

Recomendado — import online (auto-update): em Equicord > Settings > Themes cola
`https://raw.githubusercontent.com/VictorNieworld/Equicord-Themes/main/FolderColumns/FolderColumns.css`

Ou copia o `FolderColumns.css` para `%AppData%\Equicord\themes` e ativa em Settings > Themes (sem auto-update).

## Configurar

Tudo pelo modal Edit do Equicord:

- **server_listing_width_s** — largura da sidebar (62 / 126 / 184 / 242 = 1–4 colunas)
- **guildsize_s** — tamanho do ícone (50 por defeito)
- **guildgap_s** — gap entre ícones (3 por defeito)
