# FolderColumns

Layout multi-coluna para a sidebar do [BetterFolders](https://github.com/Vendicated/BetterFolders). Coloca os servidores em 1–4 colunas dentro da sidebar que abre ao clicar numa pasta, via `flex-wrap`. Não mexe na barra principal de servidores.

## Pré-requisitos

- Equicord instalado — https://github.com/Equicord
- [BetterFolders](https://github.com/Vendicated/BetterFolders) com a sidebar ativa

## Instalação

Recomendado — import online (auto-update): em Equicord > Settings > Themes cola
`https://raw.githubusercontent.com/notvictornw/Equicord-Themes/main/FolderColumns/FolderColumns.css`

Ou copia o `FolderColumns.css` para `%AppData%\Equicord\themes` e ativa em Settings > Themes (sem auto-update).

## Configuração

Tudo pelo modal Edit do Equicord:

| Variável | Descrição | Default | Min | Max |
|---|---|---|---|---|
| `server_listing_width_s` | Largura da sidebar (62/126/184/242 = 1–4 colunas) | 126 | 62 | 242 |
| `guildsize_s` | Tamanho do ícone do servidor | 50 | 10 | 200 |
| `guildgap_s` | Gap entre ícones | 3 | 0 | 25 |
